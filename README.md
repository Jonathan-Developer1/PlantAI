# TÍTULO DO PROJETO

`CURSO` Análise e Desenvolvimento de Sistemas

`DISCIPLINA` Trabalho Interdisciplinar: Aplicação Móvel 

`SEMESTRE` 4°

O PlantAÍ será uma plataforma inteligente desenvolvida para agricultores de pequeno e grande porte e auxiliadores no tratamento de doenças. Ele utilizará imagens para identificar doenças e pragas no período inicial, por meio de Inteligência Artificial. O sistema realizará uma análise da planta, identificará possíveis doenças, apresentará o nível de confiança da IA e fornecerá recomendações para auxiliar no tratamento e prevenção.
