# ConecTI

Para que o trabalho concorra à publicação na revista ConecTI, vocês precisam escrever um resumo estendido no formato do template abaixo:

https://www.canva.com/design/DAHGxO6GfJU/RtOt69yYl8N-TwnbuIdlvA/view?utm_content=DAHGxO6GfJU&utm_campaign=designshare&utm_medium=link&utm_source=publishsharelink&mode=previewLinks  

Além disso, vocês precisam assinar digitalmente o [termo](termo-de-autorizacao-ConecTI.docx) armazenado nesta pasta através da plataforma gov.br (https://www.gov.br):

O termo assinado digitalmente na plataforma gov.br, o resumo estendido e o link para o resumo estendido devem ser postados aqui neste diretório do repositório do projeto juntamente com a documentação.
